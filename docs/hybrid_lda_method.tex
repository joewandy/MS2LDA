\begin{abstract}
MS2LDA discovers recurring fragment and neutral-loss patterns, called
Mass2Motifs, by representing tandem mass spectra as documents in latent
Dirichlet allocation (LDA). Ordinary Tomotopy LDA provides effective topic
discovery, but assigning a new spectrum still requires iterative inference.
Fixed-topic variational decomposition can transfer an existing motif library,
but cannot discover motifs for a new corpus. We introduce a hybrid that keeps
classical variational LDA topic updates while using frozen DreaMS
representations in two controlled roles. Contextual peak representations
redistribute a fixed budget of topic--word prior pseudo-counts during
discovery; after topics are frozen, a whole-spectrum representation helps an
encoder initialize new-document inference. Two optional local variational
updates correct the encoder without changing the topics.

We evaluated the method on all 38,888 eligible positive-mode MSnLib spectra
with $K=1000$ and seed 42. Complete molecular scaffolds, and compound identity
where a scaffold is empty, define disjoint training, validation, and test
partitions. Vocabulary, pooled features, fitted transformations, model fitting,
and discovery convergence use training data only. Validation spectra select
the long-inference budget, and test spectra are used only for final evaluation.
All test compounds are removed from the Motif Annotation Guidance (MAG)
reference library. On 7,777 test spectra,
two-step inference reached mean
cosine 0.9889 to a validation-accepted 50-step reference, compared with 0.9240
for the encoder alone. On a frozen 128-spectrum batch after raw-file parsing,
median measured time per spectrum was 33.9 ms for two steps, 32.7 ms for the
encoder, 51.0 ms for long refinement, and 58.7 ms for Tomotopy. The
compound-balanced dominant-topic
substructure-overlap score (SOS) means were 0.6320 for two-step HybridLDA and
0.6232 for Tomotopy, with 620 and 598 evaluable topics, respectively. These
values support comparable chemical
coherence, not superiority. HybridLDA had worse word-co-occurrence NPMI, was
much slower to train, and refinement worsened document-completion likelihood.
The execution is a post-hoc implementation-corrected single-seed study, and no
independent manual motif--spectrum annotations were available. It is therefore
indicative chemical evidence, not a universal ranking.
\end{abstract}

\section{Introduction}

Tandem mass spectra contain recurring fragments and neutral losses produced by
shared molecular substructures. MS2LDA exposes these patterns by treating each
spectrum as a document, each binned fragment or loss as a word, and each latent
topic as a Mass2Motif \cite{vanderhooft2016}. A spectrum may contain several
motifs, and a motif may recur across otherwise different molecules.

Two tasks are often conflated. \emph{Topic discovery} learns the motif--word
distributions from a corpus. \emph{Decomposition} keeps an existing motif
dictionary fixed and estimates only how strongly those motifs occur in a new
spectrum. The distinction matters scientifically. Decomposition answers
``which known motifs explain this spectrum?''; discovery can answer ``which
motifs recur in this new collection?'' A faster decomposition algorithm does
not by itself improve or replace topic discovery.

Tomotopy is the reference implementation for ordinary MS2LDA discovery. It learns free LDA topics
with collapsed Gibbs sampling and then performs iterative inference for each
new spectrum. Earlier fixed-topic variational decomposition is useful when a
curated motif set should be transferred unchanged, but its topic--word
distributions are inputs rather than discoveries. Fully neural topic models
offer fast amortized inference, but they also replace the classical topic
optimizer and may suffer component collapse or unstable topic identification
\cite{srivastava2017}. These alternatives leave a gap: can classical,
auditable topic discovery be retained while new-spectrum inference approaches
encoder speed?

HybridLDA addresses that gap. Topic discovery remains a conjugate LDA expected-
count procedure. Frozen DreaMS representations \cite{bushuiev2026} provide
auxiliary spectral context, but they do not replace the observed word counts.
After discovery, topics and priors are frozen permanently. A document encoder
then learns to initialize the same local LDA posterior that ordinary
variational inference would optimize. The encoder may be used alone or followed
by a small, explicit number of local updates. This is semi-amortized inference:
one shared prediction supplies speed, and document-specific optimization
supplies correction \cite{cremer2018,kim2018}.

The main contributions are:
\begin{enumerate}
  \item a free-topic variational LDA model whose expected-count update is
        preserved, with a DreaMS-informed topic--word prior limited to a fixed
        pseudo-count budget;
  \item a strict separation between discovery and fast inference: contextual
        peak features can influence the bounded discovery prior, whereas the
        whole-spectrum embedding trains the document encoder only after topics
        are frozen;
  \item encoder-only, two-step, and long-refinement inference through one LDA
        posterior, so speed and approximation error can be measured directly;
        and
  \item a full-data, structurally held-out MSnLib benchmark with training-only
        transformations, peak-group-safe document completion, explicit MAG
        exclusion, raw-DreaMS context, and machine-verifiable publication
        artifacts.
\end{enumerate}

The novelty is not variational decomposition by itself, nor the use of a
pretrained spectrum encoder by itself. It is the combination of free classical
topic discovery, a quantitatively bounded representation-informed prior, and a
post-discovery semi-amortized inference path, evaluated on compounds unseen
during benchmark fitting. Tomotopy remains the reference implementation; this
work asks a research question rather than proposing an operational migration.

\section{How HybridLDA works}

\subsection{One model, two deliberately separated DreaMS paths}

Figure~\ref{fig:architecture} shows the design. During discovery, peak-level
DreaMS states contribute only through a bounded topic--word prior. The global
spectrum representation is not read by the discovery loop. Once the learned
topics and document-topic prior are frozen, global representations are used to
train the new-spectrum encoder. Local refinement changes only the mixture for
the current spectrum; it cannot change a discovered motif.

\subsection{Classical variational topic discovery}

Let $x_{dv}$ be the count of word $v$ in spectrum $d$, with $K$ topics and
$V$ training-vocabulary words. Conditional on the learned priors, the model is
ordinary LDA:
\begin{align}
  \boldsymbol\beta_k &\sim \operatorname{Dirichlet}(\boldsymbol\eta_k), &
  \boldsymbol\theta_d &\sim \operatorname{Dirichlet}(\boldsymbol\alpha),\\
  z_{dn} &\sim \operatorname{Categorical}(\boldsymbol\theta_d), &
  w_{dn} &\sim \operatorname{Categorical}(\boldsymbol\beta_{z_{dn}}).
\end{align}
The mean-field posterior alternates local document responsibilities with the
global update
\begin{equation}
  \lambda_{kv}=\eta_{kv}+\sum_d x_{dv}\phi_{dvk}.
  \label{eq:expected-count-update}
\end{equation}
The second term is the full-corpus expected number of assignments of word $v$
to topic $k$. Neither DreaMS path replaces it. The asymmetric
$\boldsymbol\alpha$ is re-estimated after each E-step from training-document
posteriors only. Discovery stops after both $\boldsymbol\lambda$ and
$\boldsymbol\alpha$ satisfy the frozen relative-change rule; both are then
locked before encoder training.

Tomotopy and HybridLDA therefore fit the same broad LDA factorization but use
different estimators: collapsed Gibbs sampling for Tomotopy and mean-field
variational expected counts for HybridLDA. Similar aggregate scores do not
imply identical topics, and neither estimator supplies a ground-truth motif.

\subsection{The bounded DreaMS topic--word prior}

The prior can be understood as a fixed number of \emph{starting votes} for
each topic's words. DreaMS decides how those votes are distributed; it cannot
create an unlimited number of votes. Observed training assignments are then
added through Equation~\ref{eq:expected-count-update}.

For each physical peak, the frozen DreaMS model returns a 1,024-dimensional
contextual state for at most its top 100 retained peaks. A state is accepted
only when its float32 m/z identity exactly equals the source peak identity.
The fragment and neutral-loss words made from that same peak receive the same
state. A source peak discarded by DreaMS remains unmatched and cannot borrow a
nearby peak's state. Across training spectra, these assignments are averaged
for each word. The contextual average, numerical mass, and word type are
projected into a normalized 128-dimensional word vector $\mathbf u_v$.

Each topic has a learned normalized vector $\mathbf t_k$. Their cosine-like
scores are converted into a distribution across the entire vocabulary:
\begin{align}
 p_{kv} &= \operatorname{softmax}_v
 \left(\frac{\mathbf t_k^\top\mathbf u_v}{T}\right),\\
 \eta_{kv}^{(e)} &= \eta+r_e M p_{kv},
 \qquad M=\rho\frac{N}{K}.
 \label{eq:bounded-prior}
\end{align}
Here $N$ is the number of training tokens, $T=0.5$, $\rho=0.05$, and
$r_e=\min(e/15,1)$ warms the prior over 15 epochs. Because
$\sum_v p_{kv}=1$, the structured contribution always sums to $r_eM$ for
every topic. In the executed corpus, the full contribution is about 900.5
pseudo-counts per topic. The network may concentrate or spread that mass, but
cannot increase it. This is the precise sense in which the prior is bounded.

The prior is empirical Bayes: its vectors are learned from training spectra
while the topic posterior is being estimated. Its optimizer runs only through
epoch 20 and is then fixed. The base prior $\eta=0.1$ remains everywhere, and
actual expected counts can outweigh the structured contribution. Bounded does
not mean negligible: the prior can still matter strongly for a rare word or a
sparsely supported topic-word cell.

The prior-learning objective also gives weight $10^{-3}$ to the mean squared
difference between the normalized topic-vector Gram matrix and the identity
matrix. This discourages all learned topic vectors from pointing in the same
direction. It changes only how the fixed pseudo-count budget is distributed;
it cannot increase that budget.

DreaMS is auxiliary to the LDA likelihood. Word counts alone still define
valid discovery and local-VB updates. In this benchmark both DreaMS paths are
used. Saying that the representation-informed prior is optional means that
removing its contextual contribution leaves a classical LDA update; it does
not mean that the evaluated encoder can predict without its global spectrum
representation.

\subsection{Topic-aware encoder and local correction}

After discovery, the final topic posterior supplies a count-derived evidence
vector for each spectrum. The encoder combines this evidence with the frozen
global DreaMS representation and returns
\begin{equation}
  \boldsymbol\gamma_d^{(0)}=
  \boldsymbol\alpha+N_d\widehat{\boldsymbol\pi}_d,
  \label{eq:encoder-start}
\end{equation}
where $N_d$ is the in-vocabulary token mass. Thus the encoder predicts how to
distribute the document's evidence across topics while preserving the correct
total Dirichlet mass. Its last residual layer starts at zero, so an untrained
encoder begins from evidence supplied by the learned LDA topics rather than an
unrelated coordinate system.

The encoder is fitted for 12 epochs after freezing discovery. Its loss
differentiates the exact sparse local LDA evidence lower bound (ELBO) through
two unrolled coordinate updates. A smaller encoder-only ELBO term keeps the
zero-step output useful. Topic parameters, $\boldsymbol\alpha$, and every
structured-prior parameter are checked bit-for-bit before and after this stage.

Inference has three transparent budgets. \code{infer(iter=0)} returns the
encoder initialization. Two-step inference applies exactly two ordinary local
VB updates. Long inference applies the validation-selected reference budget.
Validation mixtures after 25 and 50 steps met the frozen median and
fifth-percentile cosine thresholds, so 50 steps was accepted without invoking
the 100-step extension. All three arms share one set of frozen topics. The word
``long'' therefore means the 50-step near-converged reference selected without
test outcomes, not another model or another training run.

\section{MSnLib evaluation with genuinely unseen test compounds}

\subsection{Question, data, and compound-level split}

The central question is whether two-step HybridLDA approximates long local
optimization at near-encoder speed on benchmark-unseen compounds, while its
discovered motifs retain chemical coherence comparable to ordinary Tomotopy
LDA. The benchmark uses the positive-mode MSnLib assets deposited with Torres
Ortega et al.\ \cite{torres2026} at Zenodo record 20179680. The released MGF
contains 41,568 spectra; paper-compatible preprocessing retains all 38,888
eligible spectra. No down-sampling is used, and both models fit $K=1000$ topics.

Complete Bemis--Murcko scaffolds define a deterministic 70/10/20 split. When a
structure has an empty scaffold, its connectivity InChIKey is the group, so
unrelated acyclic compounds are not collapsed into one group. Repeated spectra
of the same compound cannot cross partitions. The resulting training,
validation, and test sets contain 27,222, 3,889, and 7,777 spectra, with zero
cross-partition scaffold-group or connectivity-identity overlap.

The test compounds must remain genuinely unseen until the final evaluation.
\emph{Information leakage} is the technical name for accidentally letting
knowledge of a test compound influence the model beforehand---for example
through another spectrum of the same compound, the vocabulary, a fitted
feature transformation, parameter selection, or the MAG search library. That
would make the test artificially easier and could inflate the reported
performance. The split and construction rules below prevent each of these
routes.

Only training spectra construct the 21,233-word vocabulary, pooled contextual
features, learned priors, and fitted transformations. Chemical names,
structures, and MAG annotations are unavailable to model fitting, convergence,
and inference-budget selection. For document completion, fragment and
neutral-loss words from one physical peak remain one indivisible group. The
test DreaMS representation is recomputed from only the observed half of those
groups after intensity renormalization; the other groups are used only for
scoring.

Before MAG indexing, every validation and test connectivity identity is
removed from the 426,280-row reference database. This excluded 53,426 rows and
retained 372,854, with zero held-out rows found by the post-build audit. MAG is
run only after model fitting and inference have completed.

\subsection{Compared methods and outcomes}

All topic-model arms use identical preprocessing, training spectra,
vocabulary, $K$, split, and seed:
\begin{enumerate}
  \item ordinary Tomotopy LDA with 100-iteration held-out inference;
  \item HybridLDA encoder-only inference;
  \item the same encoder followed by two local-VB updates; and
  \item the same Hybrid topics with 50-step long refinement.
\end{enumerate}
A raw global-DreaMS nearest-neighbour search against training spectra is a
non-topic-model context baseline. It cannot provide topics, topic coherence, or
document likelihood.

Predictive quality is held-out negative log likelihood (NLL) per
in-vocabulary token under document completion; lower is better. Approximation
to long inference is measured by cosine similarity and Jensen--Shannon
divergence between mixture vectors. Runtime is reported both with cached DreaMS
features and for a measured batch path that includes DreaMS preprocessing and
extraction for Hybrid. Both timings amortize a batch of 128 already parsed
spectra over five repeats and exclude one-time model and extractor loading.
Hybrid document construction occurs outside its timed block, whereas
Tomotopy's lightweight \code{make\_doc} call occurs inside its corresponding
block. The generated tables call this second scope ``end-to-end,'' but it is
not raw-file-to-answer latency or a cold single-spectrum measurement. Topic
diagnostics include active-topic count, top-word diversity,
training-document word-co-occurrence normalized pointwise mutual information
(NPMI), and optimally matched topic cosine and top-word Jaccard overlap.
Matching is similarity, not correctness.

The primary chemical diagnostic is the compound-balanced substructure-overlap
score (SOS) after assigning every full held-out spectrum to its
highest-probability topic. SOS compares the fingerprint bits in a topic's MAG
annotation with those in its associated test compounds; higher overlap means
the annotation and compounds share more encoded substructure features. Each
connectivity identity contributes once within a topic. This rank-based endpoint
was adopted post hoc after the published probability-$\geq0.5$ rule proved
uncalibrated across inference algorithms; the unchanged 0.5 rule is retained
only as a sensitivity analysis. SOS and MAG are indirect coherence measures.
MSnLib does not identify which peaks are true fragments or noise and cannot
establish that any learned background component is experimental background.
Independent manual motif--spectrum recovery was preferred, but no such
annotation file was present in the frozen inputs.

\subsection{Why this is an indicative one-seed result}

The executed profile uses seed 42 and multicore training: six Tomotopy workers
in partition mode and four HybridLDA intra-operation threads. This matches the
single-fit depth of the deposited MSnLib Tomotopy/SOS analysis and makes the
full $K=1000$ experiment practical on the available laptop, but it cannot
estimate cross-seed stability or provide bitwise training reproducibility.
Seeds 43--46 remain a robustness extension, not evidence silently inferred
from seed 42.

Two result-changing implementation defects were found after earlier test
results had been seen: an initially fixed, excessively concentrated
$\alpha$, and invalid peak-state pooling. The final run corrected both and
rebuilt every Hybrid-dependent artifact from epoch zero. It is explicitly
labelled a post-hoc implementation-corrected, single-seed comparison rather
than confirmatory evidence. Appendix~\ref{app:corrections} gives the complete
audit trail.

\section{Results}

\subsection{The corrected run completed as specified}

Exact peak-identity feature extraction, Hybrid discovery, encoder
finalization, all four held-out inference arms, raw DreaMS, MAG with test
compounds removed, SOS, and report generation completed under protocol
\hash{e57f289c691f94edf86e9d8b53e284233862014dd980da82e7f5f272b7f2ec45}.
Hybrid discovery satisfied the unchanged joint topic/$\alpha$ convergence rule
after 149 epochs. The fitted asymmetric $\alpha$ concentration fell from the
initial sum 600 to 9.1117 using training documents only. This sum controls how
strongly the prior spreads a spectrum across topics: the original value forced
very diffuse mixtures, whereas the learned value permits a spectrum to
concentrate on a smaller set of topics.

Hybrid discovery took 38,075 s (10 h 35 min) and finalization 897 s (15 min),
for 38,973 s of model training excluding the separately cached 1,225 s DreaMS
feature extraction. Tomotopy training took 2,427 s (40 min). HybridLDA was
therefore about 16 times slower to fit in this laptop execution and used
3.75 GB peak RSS, compared with 1.71 GB for Tomotopy. The claimed speed benefit
is new-spectrum inference, not training.

\subsection{Two local steps recover most of the long-inference mixture}

Encoder-only inference had mean and median cosine 0.9240 and 0.9509 to the
50-step reference, but the fifth percentile was 0.7684. Two local updates
raised the mean to 0.9889, the median to 0.9996, and the fifth percentile to
0.9417; mean Jensen--Shannon divergence fell from 0.0569 to 0.0120. The main
gain is therefore in the hard tail that a median alone would hide.

On cached features, two-step HybridLDA took 2.92 ms per spectrum versus
58.63 ms for Tomotopy, a conditional 20-fold model-only difference. That is
not the appropriate headline when a spectrum's DreaMS representation has not
been precomputed. On the frozen 128-spectrum batch, the broader measured path
took 33.90 ms per spectrum for two-step inference, only 1.17 ms (3.6\%) more
than encoder-only inference, versus 50.96 ms for long refinement and 58.74 ms
for Tomotopy. Under this specific batch and timing boundary, two-step HybridLDA
was approximately 1.7-fold faster than Tomotopy while remaining close to
encoder speed. Cold-start and one-at-a-time latency were not measured.

\subsection{Closeness to long inference is not the same as predictive gain}

Tomotopy achieved held-out NLL 9.7569 per token and the Hybrid encoder 9.7685.
Two-step and long refinement were worse at 10.0795 and 10.1910. Local VB
optimizes the observed completion half, not prediction of its hidden partner,
so moving toward the long observed-data solution need not improve completion
likelihood. These data support the claim that two steps approximate the chosen
long-inference procedure. They do not support a claim that refinement improves
held-out prediction, nor that HybridLDA beats Tomotopy on NLL.

\subsection{Chemical coherence is comparable in this seed}

Under the primary compound-balanced dominant-topic endpoint, Tomotopy had 598
SOS-evaluable topics with mean 0.6232. HybridLDA had 602, 620, and 626
evaluable topics for encoder-only, two-step, and long inference, with means
0.6278, 0.6320, and 0.6299. MAG annotations were available for 607 Tomotopy
topics and 632 Hybrid topics. The Hybrid values are close to Tomotopy and do
not materially separate as local refinement changes, which is consistent with comparable
aggregate coherence. The small numerical differences have no seed-level
uncertainty estimate and do not establish superiority.

Here, ``SOS-evaluable'' means that a topic has both a usable MAG annotation and
at least one associated held-out compound after all exclusions; it is not a
claim that the topic is chemically correct.

The frozen probability-$\geq0.5$ sensitivity tells a different coverage
story. It yielded 333 evaluable Tomotopy topics, but only 179, 55, and 64
Hybrid topics for encoder, two-step, and long inference. Only 961 Tomotopy test
spectra and 543, 96, and 114 Hybrid test spectra crossed the cutoff. This
confirms that 0.5 is an algorithm-dependent calibration choice, not a universal
definition of topic membership. It was not lowered after seeing the results;
instead, the cutoff-free dominant-topic analysis is disclosed as the post-hoc
primary endpoint and the original rule remains visible as a sensitivity.

\subsection{The methods discover different topic dictionaries}

HybridLDA had slightly greater top-word diversity than Tomotopy (0.8387 versus
0.8148), but worse mean word-co-occurrence NPMI ($-0.4744$ versus $-0.2997$).
Of 45,000 top-word pairs per method, 25,599 Hybrid pairs and 20,537 Tomotopy
pairs never co-occurred and received the frozen worst score of $-1$. The NPMI
gap is therefore a substantive counter-result, not a formatting artefact.

After optimal same-seed topic matching, mean full-vocabulary cosine was 0.4768
and mean top-word Jaccard was 0.0816. Of the 1,000 matched pairs, 475 had MAG
annotations on both sides; their mean MACCS-consensus Jaccard was 0.5483.
Comparable aggregate SOS therefore does not mean that Tomotopy and HybridLDA
found the same motifs. Raw DreaMS nearest neighbours had mean Morgan similarity
0.2207 and zero exact connectivity or scaffold matches under the structural
split. That baseline provides context for the difficulty of the held-out set,
not a topic-model ranking.

\section{Discussion}

\subsection{Answer to the scientific question}

For this corrected seed-42 execution, the answer is provisionally yes:
two-step HybridLDA estimates mixtures close to 50-step local optimization,
adds little time over the encoder, is faster than Tomotopy within the measured
128-spectrum batch boundary, and
produces aggregate SOS comparable to Tomotopy on structurally held-out
compounds. The answer is deliberately narrower than ``HybridLDA is better.''
Tomotopy has marginally better completion NLL, better NPMI, far lower training
cost, and remains the reference comparison method. One post-hoc corrected seed cannot
establish stability, superiority, or generality.

\subsection{Novelty relative to Tomotopy and fixed-topic decomposition}

Relative to Tomotopy, HybridLDA contributes two forms of controlled transfer
from a pretrained spectral representation. The peak-level path changes the
inductive bias for discovering topics, while its fixed mass prevents the
neural similarity scores from overwhelming the LDA count update simply by
growing in scale. The spectrum-level path learns a direct map to a posterior
initializer after topics are known. Tomotopy has neither path: it discovers
topics from discrete counts and performs iterative new-document inference.

Relative to old fixed-topic VB decomposition, the key novelty is not the local
coordinate update. Both methods can optimize a document mixture against fixed
topics. The old decomposition begins with a motif dictionary learned
elsewhere and leaves it unchanged. HybridLDA first discovers its own
corpus-specific topics, learns an encoder anchored to those particular topics,
and then exposes the coordinate update as an optional correction. This makes
it a discovery-and-inference method rather than only a motif-transfer method.

The separation also preserves interpretability of the scientific comparison.
Global DreaMS embeddings never train the topics through the encoder, and the
encoder cannot repair or rewrite a motif. Peak context can bias discovery, but
only through the explicit pseudo-count budget. The resulting model remains LDA
with an empirical-Bayes prior, not an unconstrained neural topic generator.

\subsection{What the bounded prior does and does not guarantee}

The fixed budget is a scale guarantee, not a chemistry guarantee. It prevents
the learned prior from adding arbitrarily large total evidence, but it does not
ensure that its preferred words form a chemically meaningful motif. A
concentrated 900.5-count allocation can still strongly influence rare words,
and DreaMS was trained to represent whole spectra rather than substructures.
The worse NPMI result is therefore important: chemical context encoded by
DreaMS did not translate automatically into stronger discrete co-occurrence
among the ten highest-probability words.

The two DreaMS paths should also not be credited for the same result. Topic
coherence can be affected only by the peak-level prior path, because global
embeddings are introduced after topic freezing. Inference speed and
approximation to long mixtures depend on the global path. Keeping those claims
separate avoids attributing a fast encoder result to topic discovery or a topic
result to the post-discovery encoder.

\subsection{Limitations and next evidence}

The principal limitations are scientific:
\begin{itemize}
  \item Only seed 42 was executed, using non-bitwise-reproducible multicore
        fitting. Cross-seed topic stability is unavailable. Repeating seeds
        43--46 would measure robustness but would remain post hoc.
  \item The exact-identity correction and dominant-topic SOS endpoint were
        defined after earlier test results were inspected. The correction is
        necessary for validity, but this dataset can no longer provide pristine
        confirmatory evidence for those choices.
  \item The structural split proves that compounds are unseen by benchmark
        fitting. It cannot prove that they were absent from DreaMS pretraining,
        because no complete identity-level pretraining manifest is available.
  \item SOS and MAG use structures and automated annotations after inference;
        they measure coherence, not peak-level correctness. Independent manual
        motif--spectrum annotations were unavailable and no substitute was
        relabelled as ground truth.
  \item The prior mass, temperature, warm-up, two-step objective, and
        encoder-only loss weight were development choices rather than values
        selected on an untouched external study.
  \item Timing is hardware-, batch-, and implementation-specific. DreaMS
        extraction dominates the broader Hybrid path, so the 20-fold cached
        comparison applies only when those features already exist. Raw-file
        parsing, one-time initialization, and cold single-spectrum latency were
        not measured; Hybrid document construction was also outside its timed
        block.
\end{itemize}

The most informative next study is therefore an untouched, structurally
grouped dataset with prespecified dominant-topic and secondary-motif endpoints,
independent manual motif--spectrum annotations, and all planned seeds reported.
It should retain explicitly bounded full-path timing and NPMI as
counter-balancing outcomes rather
than optimizing only for SOS.

\section{Conclusion}

HybridLDA combines free classical topic discovery with a bounded
DreaMS-informed word prior and a separate semi-amortized new-spectrum encoder.
The corrected full-data MSnLib run shows that two local updates remove most of
the encoder's hard-tail error while adding little time in the measured batch
setting. On the
primary compound-balanced SOS diagnostic, HybridLDA and Tomotopy have similar
coverage and mean coherence on benchmark-unseen compounds. The same execution
also shows the costs and counter-results clearly: slower training, higher
memory, worse NPMI, and no likelihood benefit from refinement. The contribution
is therefore a promising and testable speed--inference architecture with
comparable one-seed chemical coherence, not proof that HybridLDA discovers
better motifs or should replace Tomotopy.

\section{Complete local-inference specification}
\label{app:inference}

For the final topic posterior, define
\begin{align}
 \ell_{kv} &= \psi(\lambda_{kv})-
 \psi\left(\sum_u\lambda_{ku}\right),\\
 r_{vk} &= \operatorname{softmax}_k(\ell_{kv}),\\
 e_{dk} &= \sum_v\frac{x_{dv}}{N_d}r_{vk}.
\end{align}
The global DreaMS vector $\mathbf s_d\in\mathbb R^{1024}$ is projected to 128
dimensions and concatenated with $\mathbf e_d$. Two 256-unit ReLU layers
produce a residual $\mathbf a_d$:
\begin{align}
 \mathbf p_d&=\operatorname{LN}_2\!\left(
 \operatorname{GELU}\left[W_s\operatorname{LN}_1(\mathbf s_d)+\mathbf b_s\right]
 \right),\\
 \widehat{\boldsymbol\pi}_d&=\operatorname{softmax}\left(
 \log[\max(\mathbf e_d,\epsilon)]+g_\omega[\mathbf e_d;\mathbf p_d]\right),\\
 \boldsymbol\gamma_d^{(0)}&=\boldsymbol\alpha+
 N_d\widehat{\boldsymbol\pi}_d.
\end{align}

For a candidate posterior $\boldsymbol\gamma_d$, the encoder-dependent local
sparse LDA ELBO is
\begin{equation}
 \mathcal L_d(\boldsymbol\gamma_d;\boldsymbol\lambda)
 =-\operatorname{KL}\!\left[
 \operatorname{Dir}(\boldsymbol\gamma_d)\Vert
 \operatorname{Dir}(\boldsymbol\alpha)\right]
 +\sum_v x_{dv}\operatorname{LSE}_k\left(
 \bar\theta_{dk}+\ell_{kv}\right),
\end{equation}
where
$\bar\theta_{dk}=\psi(\gamma_{dk})-\psi(\sum_j\gamma_{dj})$.
Two differentiable coordinate steps are
\begin{align}
 \phi_{dvk}^{(t)}&=\operatorname{softmax}_k(
 \bar\theta_{dk}^{(t)}+\ell_{kv}),\\
 \gamma_{dk}^{(t+1)}&=\alpha_k+\sum_vx_{dv}\phi_{dvk}^{(t)}.
\end{align}
Only encoder and spectrum-projection parameters receive gradients from
\begin{equation}
 \mathcal J_{\mathrm{SA}}=-\frac{\sum_d[
 \mathcal L_d(\boldsymbol\gamma_d^{(2)};\boldsymbol\lambda)
 +0.1\mathcal L_d(\boldsymbol\gamma_d^{(0)};\boldsymbol\lambda)]}
 {\sum_dN_d}.
\end{equation}
Topics, alpha, and structured-prior parameters remain frozen. Training uses
uniform-document random reshuffling, the correctly scaled minibatch estimator,
Adam, and gradient-norm clipping. No adaptive stopping occurs inside the
differentiable graph. At inference, a positive tolerance can stop a requested
maximum budget when the batch-level relative gamma change falls below the
threshold.

\section{Implementation-correction audit trail}
\label{app:corrections}

The first seed-42 Hybrid execution treated configured $\alpha=0.6$ as a fixed
value for each of 1,000 topics, giving total concentration 600 while Tomotopy
optimized its document prior. This forced diffuse Hybrid mixtures and made the
0.5 membership comparison meaningless. HybridLDA now treats 0.6 as an
initialization and estimates an asymmetric vector from training documents with
a guarded, objective-nondecreasing Newton step. The executed fit ended at
total concentration 9.1117.

Independent review then found two peak-pooling defects. First, document-level
rounded-word pooling could collapse separate physical peaks into one contextual
state. A first correction iterated over peaks, but matched each source group to
the nearest DreaMS-retained peak within 0.02 Da. Because DreaMS keeps at most
100 peaks, a discarded peak could borrow a nearby retained state. A read-only
audit found this aliasing in 158 of 27,222 training spectra, involving 708
reused states and 743 extra physical groups.

The final implementation accepts only exact float32 source/retained m/z
identity, leaves discarded groups unmatched, and fails closed on duplicate
identities. In the completed cache, 672,575 of 678,813 training peak groups
matched retained states and 6,238 remained unmatched. Fragment and loss words
from each matched physical peak stayed together. Chunk identifiers and hashes
make interrupted cache construction resumable without double accumulation.

All prior Hybrid feature caches, checkpoints, mixtures, MAG outputs, SOS
values, and interpretations were invalidated and excluded from publication;
superseded Hybrid model and result directories were removed. Any older cache
material retained outside the active run is ineligible for resumption. The
corrected run started Hybrid discovery from epoch zero and reused only the
byte-verified Tomotopy model, which does not consume DreaMS peak states. Its
frozen derivation records that earlier test results had been inspected and that
only the implementation, not the scientific settings, changed.

The generic exported \code{pool\_word\_embeddings} convenience helper is not
part of this executed path. It starts from rounded token strings and performs
approximate mass matching, so it cannot recover the exact physical-peak
identity required by this protocol. The benchmark instead uses its
peak-group-aware exact-identity builder; no publication claim is made for the
generic helper.
